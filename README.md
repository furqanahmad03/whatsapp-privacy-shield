# WhatsApp Privacy Shield

WhatsApp Privacy Shield is a Chrome extension that helps keep your conversations private while using WhatsApp Web. It can blur or hide sensitive information, making it useful in shared spaces, during screen sharing, or whenever someone is nearby.

## Features

- Blur contact and group names
- Blur profile pictures and message previews
- Blur timestamps and unread counters
- Hide the complete chat sidebar
- Protect opened-chat header details
- Choose from multiple privacy styles and blur strengths
- Instantly protect everything with the panic button
- Keep the currently opened chat visible if preferred
- Quickly switch privacy protection on or off
- Save your preferences automatically

## Privacy

The extension works entirely inside your browser. It does not collect, save, or transmit your conversations, contact details, screenshots, or browsing activity.

## Install in Chrome

1. Build the project to create the `dist` folder.
2. Open `chrome://extensions` in Chrome.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the `dist` folder.
5. Open WhatsApp Web and use the extension from the Chrome toolbar.
